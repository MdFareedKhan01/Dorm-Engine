## 🛠️ Setup Instructions

1. Install Volta:-
2. winget install Volta.Volta
3. Clone repo:-
4. git clone https://github.com/MdFareedKhan01/Dorm-Engine
5. change branch :-
6. git checkout dev
7. git pull origin dev
4. in apps/server , rename "env.example" to ".env"
5. cd dorm-engine
3. Install dependencies:-
4. npm install
5. Run project:-
6. npm run dev
---

## 🌿 Git Workflow

* Always work on feature branches
* Base branch: dev
* Never push directly to main
